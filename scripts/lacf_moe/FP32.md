# Cached LACF-MoE FP32

`python -u -m scripts.lacf_moe.train_fp32` runs the owner-authorized fresh
F1--F4, seed1234 queue. Use its prepared guarded launch script in
`outputs/lacf_moe/fp32/launch/run.sh`; it refuses existing launches/runs.

Same three-expert architecture, original eight concepts and BCE-only recipe as
main LACF-MoE. All trainable-model operations run in FP32; autocast and TF32 are
disabled. Reuses the original verified frozen encoder cache, whose extraction
precision is unchanged. Batch132, AdamW3e-4/wd1e-4, constant LR, max30/patience5,
source macro EER selection, seed1234, fixed views and domain/class sampling stay
the same. Encoders are not loaded. No automatic target evaluation or retries.

Outputs: `outputs/lacf_moe/fp32/f1/1234/` through `f4/1234/`: best/last checkpoints,
history, training log, source score CSVs, source calibration, routing and bound
completion/score manifests. Historical runs are preserved. Launch/preflight
evidence and a combined live log are under `outputs/lacf_moe/fp32/launch/`.
