# FP32 LACF-MoE ablations

The owner-authorized dependent queue runs the existing A1--A6, B1--B6 and
C1--C3 controls, each F1--F4 seed1234: 60fresh fits. A0/C0 reuses the completed
main FP32 folds. It starts only after the main queue has a successful producer
exit plus four verified completions. Its initial wait uses no CUDA context or
duplicate feature bank. No automatic retry/resume/overwrite.

Entrypoint: `python -u -m scripts.experiments.lacf_moe_ablations.train_fp32`.
Use `outputs/experiments/lacf_moe_ablations/fp32/launch/run.sh` in tmux
`lacf-moe-ablations-fp32`. Log/progress/status and dependency evidence stay under
that launch folder. All controls share one loaded, verified frozen source bank.

All trainable computation and source selection/scoring are FP32, TF32 disabled.
Models, original concepts, per-control objectives, batch132, AdamW3e-4/wd1e-4,
constant LR, max30/patience5, seed1234, sampling and views are unchanged. C1
adds semantic BCE0.25; C2 adds bona-fide JS0.10; C3 adds both. Encoders are not
loaded or re-extracted. Preserve original BF16 artifacts and active sources.

Outputs `outputs/experiments/lacf_moe_ablations/fp32/<ID_name>/<fold>/1234/`
contain checkpoints, epoch history/logs, FP32 source score CSVs, calibration,
routing, metrics and hash-bound completion. This queues training only, not
target evaluation, new CLAP repair/random anchors or three-seed inner rotations.


## Subsequent evaluation authorization

The owner subsequently authorized all 60 fixed FP32 control evaluations and
the eight embedding-path evaluations. One shared sequential worker runs
`python -u -m scripts.experiments.lacf_moe_ablations.evaluate_fp32`, with its
launch/progress under `outputs/experiments/lacf_moe_fp32_evaluations/launch/`.
It evaluates verified completed cases while the remaining fits train, when
GPU and RAM allow. Both families share one bounded source-dev cache, and
ready embedding-path cases alternate with ablations. No encoders execute.

Each fit requires producer/config/artifact verification and fresh full-source
FP32 score parity before canonical cached target access. Source calibration
stays fixed. Results include EER/AUROC, raw and separate transductive z-score
APCER/BPCER/ACER at source 1%, 5%, 10%, with 1,000 conditional bootstrap
resamples, seed 2026. Historical extraction precision stays unchanged; these
remain exploratory single-seed results after prior target exposure.

Results: `outputs/experiments/lacf_moe_ablations/fp32/evaluations/<ID_name>/<fold>/1234/`
and `outputs/experiments/lacf_moe_embedding_paths/fp32/evaluations/<variant>/<fold>/1234/`.
Two CPU threads, no feature workers, 1GiB GPU tensor cap and >=2GiB GPU free;
only current-fold source-dev partitions retained with an 8GiB RAM reserve.
No overwrite/resume/retry; failed producer/source gates stop before targets.
The separately stopped SSL F3 evaluation remains held.
